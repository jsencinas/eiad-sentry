# Venv Stream

Entorno de Python para procesamiento de imágenes y video
del proyecto EIAD-Sentry.

## Instalación en Raspberry Pi

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

## Dependencias

- NumPy
- OpenCV Python Headless

El entorno virtual no se incluye en GitHub.
Se debe reconstruir en cada dispositivo.
